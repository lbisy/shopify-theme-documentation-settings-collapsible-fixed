# 新版补充板块

本页汇总新版安装包中存在、原中文文档尚未单独介绍的板块。这里的“补充”指文档覆盖范围，不表示它们一定是在本次主题版本首次推出。

## 展示板块

| 板块 | 用途 |
| --- | --- |
| [商品系列卡片列表（Collection list）](/zh/sections/collection-list) | 选择多个商品系列，以卡片形式提供分类入口，适合展示不同品类或主题系列。 |
| [编辑式图片拼贴（Editorial collage）](/zh/sections/editorial-collage) | 将标题、品牌说明与三张不同用途的图片组合展示，适合介绍品牌故事、商品质感和细节。 |
| [图片热点与特色标签（Feature tabs）](/zh/sections/feature-tabs) | 通过主图、定位标记和对应的文字内容介绍商品特色，可为每个内容块关联商品。 |
| [配方与成分介绍（Formula details）](/zh/sections/formula-details) | 结合顶部介绍区域、配方属性和成分内容块，展示配方理念、产品属性及成分说明。 |
| [心情选品展示（Mood finder）](/zh/sections/mood-finder) | 用不同心情或使用情境组织商品推荐，每个内容块可配置图片、推荐商品和介绍文字。 |
| [步骤与使用仪式（Ritual steps）](/zh/sections/ritual-steps) | 按步骤介绍使用方法或搭配流程，可在每一步加入图片、商品和链接。 |
| [错落图片画廊（Scatter gallery）](/zh/sections/scatter-gallery) | 通过多张图片组成错落的视觉展示，适合营造品牌氛围或呈现场景照片。 |

## 页面主分区与全局区域

| 板块 | 用途 |
| --- | --- |
| [公告栏（Announcement bar）](/zh/sections/announcement-bar) | 在页眉组内展示公告文字和链接，也可配置社交入口、国家及语言选择器。 |
| [页眉（Header）](/zh/sections/header) | 配置全站 Logo 位置、导航菜单、超级菜单以及国家和语言选择器。 |
| [页脚（Footer）](/zh/sections/footer) | 在页脚组中展示品牌信息、说明文字、链接列和 Follow on Shop 入口。 |
| [商品详情主分区（Product）](/zh/sections/product) | 配置商品详情页的媒体展示与商品信息区，通过内容块组织标题、价格、规格、库存提示和购买操作。 |
| [商品系列主分区（Collection）](/zh/sections/collection) | 配置单个商品系列页面的头图、说明、商品网格、筛选、排序和分页数量。 |
| [购物车主分区（Cart）](/zh/sections/cart) | 配置独立购物车页面的配色、标题字号、继续购物链接及上下留白。 |
| [搜索结果主分区（Search）](/zh/sections/search) | 配置搜索结果页面的配色、每页结果数量、移动端商品列数和上下留白。 |
| [博客列表主分区（Blog）](/zh/sections/blog) | 配置博客列表页的头部信息、装饰徽章、文章分页数量和阅读链接文字。 |
| [博客文章主分区（Article）](/zh/sections/article) | 配置文章页的页头和内容配色、图片、标题、辅助文字及社交分享显示。 |
| [关于我们主分区（About us）](/zh/sections/main-page-about) | 在页面模板中展示品牌介绍图片、引导文字、标题和说明。 |
| [联系我们主分区（Contact us）](/zh/sections/main-page-contact) | 配置联系页面的介绍区域和表单外观，包括图片、标题、表单配色、提交按钮与成功提示。 |
