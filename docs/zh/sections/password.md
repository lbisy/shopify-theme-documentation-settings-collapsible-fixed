# Password（密码页主体）

**Password** 分区是商店密码模板的主要内容区域。店面限制访问期间，可用它展示即将上线的通知并收集访客邮箱。该分区控制页面中央的标题、说明文字和订阅表单，但不会设置或修改商店访问密码。

![Password 分区设置面板与前台效果](/images/zh/password.png)

## 打开 Password 分区

1. 进入 **Shopify 后台 → 在线商店 → 主题**。
2. 在需要编辑的主题上点击 **自定义**。
3. 打开编辑器顶部的模板选择器，选择 **Password（密码）**。
4. 在左侧 **Template（模板）** 下选择 **Password**，不要与 **Password header** 或 **Password footer** 混淆。
5. 配置各项设置，并同步查看店面预览。
6. 点击右上角的 **保存**。

密码模板通常只会在商店启用密码保护时对访客显示，也可以直接在主题编辑器中选择该模板进行预览。

## Color scheme（配色方案）

选择当前分区使用的全局配色方案。它会影响分区背景、标题与说明文字、输入框、按钮、边框以及主题定义的其他状态样式。

点击 **Edit scheme（编辑方案）** 可以修改所选全局方案。由于同一个方案可能被多个分区共用，修改后应检查其他页面，并确认普通文字、占位文字、输入框边框、按钮、焦点环和验证提示与背景之间具有足够的对比度。

## Heading（标题）

填写密码页的主标题，例如 `即将上线`。建议保持简短，避免移动端换行过多或把订阅表单推到页面下方。

字段右侧的动态来源图标可在存在兼容来源时使用。商店启用多语言后，应分别翻译标题，不要在同一个字段中堆叠多种语言。

## Message（说明文字）

填写标题下方的补充说明，告诉访客商店将提供什么内容，以及订阅邮箱后可以获得哪些更新。富文本编辑器支持粗体、斜体、链接和列表等基础格式，也可以连接兼容的动态来源。

文案应简洁、具体。只有在商店确实能够兑现时，才承诺上线时间、折扣或专属优惠。若订阅涉及隐私、促销或其他条件，应链接到相应的隐私政策或条款页面。

## Email placeholder（邮箱占位文字）

设置邮箱输入框中的提示文字，例如 `邮箱` 或 `请输入邮箱地址`。占位文字应保持简短，不要把重要的同意说明放在这里，因为访客开始输入后它会消失。

该设置只会更改输入框的占位文字。订阅按钮文字以及成功、错误提示通常需要在主题的语言翻译中修改。

## Padding（上下间距）

- **Padding top**：控制标题和表单上方的留白。
- **Padding bottom**：控制表单下方与密码页页脚之间的留白。

截图中两个值均为 `32 px`。可以先保持一致，再根据桌面端和移动端的实际排版调整；说明文字换行较多时，应特别检查页面纵向高度。

## Custom CSS（自定义 CSS）

**Custom CSS** 用于添加内置设置无法完成的小范围分区样式。应优先使用分区设置和全局主题设置；自定义选择器需要限定在当前分区内，不要隐藏表单标签、验证提示或键盘焦点状态，并在主题更新后重新检查效果。

## 订阅表单行为

- 分别使用有效、无效和重复邮箱测试表单。
- 确认成功提交后，数据出现在预期的 Shopify 客户或邮件营销记录中。
- 检查加载中、成功和错误反馈是否清晰可见。
- 使用键盘检查焦点顺序，并通过 `Enter` 键提交表单。
- 检查移动端软键盘、输入框宽度和按钮排列。
- 根据商店实际销售地区配置适用的隐私和订阅同意说明。

预览顶部的 **Enter using password（使用密码进入）** 链接属于 **Password header** 分区；社交图标、Shopify 署名和店主登录链接属于 **Password footer** 分区，不在当前分区中设置。

## 发布前检查

1. 替换所有默认文案，并翻译标题、说明、占位文字、按钮和表单反馈。
2. 检查所选配色方案中的文字、输入框、按钮、边框和焦点环对比度。
3. 使用真实验证流程测试订阅表单，并在 Shopify 后台确认生成的记录。
4. 检查桌面端和移动端布局，包括较长的多语言文案。
5. 仅使用键盘完成操作，并确认邮箱输入框具有可访问名称。
6. 核对隐私链接、订阅同意说明和促销承诺。
7. 确认密码进入链接可用，并保持 Password header、Password 和 Password footer 的视觉风格一致。
8. 保存主题后，在无痕窗口打开密码页，完成一次端到端测试。
