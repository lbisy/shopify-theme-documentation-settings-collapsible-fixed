# 精选客户评价（Featured testimonial）

Featured testimonial 将评价卡片排成上下两行，以连续滚动的形式展示图片、评价、星级和作者。分区设置控制标题、两排卡片配色、滚动宽度、方向和速度；每个 **Testimonial** 小块单独配置一条评价。

![Testimonial Featured 设置面板与前台效果](/images/zh/testimonial-featured.png)

## 添加与配置

1. 进入 **Shopify 后台 → 在线商店 → 主题 → 自定义**。
2. 打开需要编辑的页面模板，在页面内容区域选择 **添加分区 → Featured testimonial**。
3. 设置分区配色、标题和标题字号。
4. 分别选择上下两排卡片的配色方案。
5. 展开分区并点击 **添加 Testimonial**，配置图片、评分、评价和作者。
6. 按需添加其他评价，拖动小块调整内容顺序。
7. 设置滚动宽度、方向、速度和悬停暂停，预览桌面端与移动端后点击 **保存**。

此分区不能添加到页眉、页脚或自定义弹层分组中。截图中的左右重复卡片属于循环展示效果，无需为延长滚动区域手动复制相同评价。

## 配色（Color scheme）

选择整个分区使用的全局配色方案。截图中第一行第二个配色缩略图被选中，作为标题及评价区域的整体配色。

点击 **编辑方案** 可修改所选方案。其他使用同一方案的区域也会受到影响，请一起检查。评价卡片本身的配色在 Cards 中分别配置。

## 标题（Heading）

| 设置项 | 截图当前值 | 作用 |
| --- | --- | --- |
| **Heading** | `Beyond clients. Trusted partners.` | 设置评价分区的主标题。 |
| **Heading size** | **2X large** | 调整主标题的字号。 |

Heading 支持加粗、斜体和链接等行内格式。Heading size 可选 **Extra small、Small、Medium、Large、Extra large、2X large、3X large、4X large**。

截图中的标题文字和字号与安装包默认值一致。标题较长时会随可用宽度换行，请检查桌面端和移动端是否仍然清晰。

## 卡片配色（Cards）

| 设置项 | 截图当前值 | 作用 |
| --- | --- | --- |
| **Top row card color scheme** | 第一行第一个配色缩略图被选中 | 设置上排评价卡片的配色。 |
| **Bottom row card color scheme** | 第一行第二个配色缩略图被选中 | 设置下排评价卡片的配色。 |

截图中，上排卡片呈深色背景，下排卡片呈浅色背景，形成两排之间的视觉区分。这两项与安装包默认方案分别为 scheme-1、scheme-2 的设置一致；实际颜色取决于店铺中的方案内容。

两排配色可独立选择，通过各自的 **编辑方案** 修改。请分别检查评价文字、星级和作者署名在深浅背景上的可读性。

## 连续滚动（Marquee）

| 设置项 | 截图当前值 | 作用 |
| --- | --- | --- |
| **Marquee width** | **Full width** | 设置评价滚动区域使用页面内容宽度或全宽。 |
| **Direction** | **Right to left** | 设置滚动方向。 |
| **Speed** | **Normal** | 设置移动速度。 |
| **Pause on hover** | **开启** | 在支持悬停的设备上，指针移到滚动区域时暂停。 |

### 宽度与方向

- **Page width**：滚动区域跟随页面内容宽度，也是安装包默认值。
- **Full width**：滚动区域使用全宽，为截图当前选择。
- **Right to left**：从右向左移动，为截图当前值及默认值。
- **Left to right**：从左向右移动。

这里控制的是评价滚动区域的宽度，不是单张卡片宽度。使用 Full width 时，请检查两侧边缘的内容进入、离开及循环衔接效果。

### 速度与暂停

Speed 可选 **Slow、Normal、Fast**。截图使用 Normal，与默认值一致；较长评价建议使用更舒缓的速度，并开启悬停暂停，便于阅读。

Pause on hover 在截图中已开启，也与默认值一致。触摸设备没有持续悬停状态，应单独检查移动端的阅读体验。这是连续滚动速度设置，不是按秒切换单条评价的间隔设置。

## 上下间距（Padding）

| 设置项 | 截图当前值 | 作用 |
| --- | --- | --- |
| **Padding top** | `32 px` | 调整分区顶部留白。 |
| **Padding bottom** | `32 px` | 调整分区底部留白。 |

两项范围均为 **0–100 px**，步长为 **4 px**。截图与安装包默认值均为 `32 px`。

## Testimonial 小块

每个 **Testimonial** 对应一条评价。点击左侧已有小块编辑，或通过 **添加 Testimonial** 新增。

| 设置项 | 截图当前值 | 作用 |
| --- | --- | --- |
| **Image** | 未显示已选图片缩略图 | 选择当前评价卡片中的图片。 |
| **Show image** | **开启** | 控制是否显示当前卡片的图片区域。 |
| **Star rating** | `5` | 设置卡片中的星级评分。 |
| **Quote** | 下方示例文案 | 填写评价正文，支持富文本。 |
| **Author name** | `Alexandria Maria` | 填写作者署名，支持行内富文本。 |

### 图片与显示开关

点击 **Image → 选择** 可选择或上传图片，也可浏览免费图片。图片属于当前 Testimonial，不是整个分区共用的主视觉。

**Show image** 在截图中开启，与默认值一致。开启后显示图片区域；未选择图片时，主题会使用装饰占位图，截图预览中的商品线稿即为此类展示。若只需要文字评价，可关闭 Show image。

### 评分、评价与署名

**Star rating** 可设置为 **1–5 星**，步长为 **1**。截图为 `5`，与默认值一致，请按实际评价填写。

截图中的 Quote 为：

> A calm, considered edit that makes everyday skincare feel easier to explore.

Quote 支持段落、加粗、斜体、链接和列表等富文本格式。建议文案简洁，较长内容需要在卡片中检查可见范围和阅读效果。

**Author name** 在截图中为 `Alexandria Maria`，前台以署名形式显示。安装包默认文字为 `Customer name`；填写后请检查长名字的换行与卡片内布局。

### 排序与移除

- 点击 **添加 Testimonial** 增加一条评价。
- 拖动左侧 Testimonial 小块，调整内容顺序，并在预览中检查两排卡片的排列效果。
- 点击小块底部的 **移除区块**，仅移除当前评价。

## 自定义 CSS

**自定义 CSS** 是主题编辑器提供的分区样式入口。优先使用现有配色、宽度、速度和间距设置；添加局部样式后，请检查卡片排版、移动端布局与循环衔接。

## 保存并检查

- 标题为 Beyond clients. Trusted partners.，字号为 2X large。
- 上排深色卡片、下排浅色卡片中的文字和评分均清晰可读。
- Full width 滚动区域以 Normal 速度从右向左移动，循环时没有明显跳动。
- 桌面端悬停可暂停，移动端评价仍便于阅读。
- 各小块的图片开关、评分、正文和署名填写正确。
- 上下 `32 px` 留白与相邻分区协调。
