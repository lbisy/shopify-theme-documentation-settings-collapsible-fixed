# Password Header（密码页页眉）

**Password header** 是商店密码模板顶部的品牌与访问入口区域。它可以显示所选 Logo 或商店名称，并为已经获得店面密码的访客提供 **Enter using password（使用密码进入）** 链接。

![Password header 设置面板与前台效果](/images/zh/password-header.png)

## 打开 Password header

1. 进入 **Shopify 后台 → 在线商店 → 主题**。
2. 在需要编辑的主题上点击 **自定义**。
3. 打开编辑器顶部的模板选择器，选择 **Password（密码）**。
4. 在左侧 **Template（模板）** 下选择 **Password header**。
5. 配置各项设置，并同步查看店面预览。
6. 点击右上角的 **保存**。

Password header 是密码模板结构的一部分。上线通知与邮箱订阅表单在 **Password** 分区中配置；社交链接和店主信息则在 **Password footer** 中配置。

## Color scheme（配色方案）

选择页眉使用的全局配色方案。它会影响页眉背景、商店名称或 Logo 所处区域、密码进入链接、边框、焦点状态以及主题定义的其他颜色。

点击 **Edit scheme（编辑方案）** 可以修改所选全局方案。一个方案可能被多个分区共用，因此修改后需要检查所有使用该方案的区域。密码进入链接在默认、悬停和键盘焦点状态下都应清晰可见。

## Padding（上下间距）

- **Padding top**：控制 Logo、商店名称和密码进入链接上方的留白。
- **Padding bottom**：控制页眉内容下方与 Password 主体分区之间的留白。

截图中两个值均为 `32 px`，可以作为平衡的初始设置。仅在移动端页眉显得过高时适当减小，并确认内容不会紧贴屏幕边缘。

## Theme Settings：Logo

在 **Theme Settings** 设置组中使用 **Logo** 选择 Password header 显示的品牌图片。图片选择器可使用已上传素材、可用的免费图片或兼容的动态来源。

如果未选择 Logo，主题可以像截图一样以文字显示商店名称。这是有效的后备方案，但仍应在 Shopify 后台检查商店名称的拼写和大小写。

选择 Logo 时建议：

- 使用清晰且适合高像素密度屏幕的图片。
- 页眉配色可能变化时，优先使用透明背景素材。
- 确保品牌关键细节在较小的页眉尺寸下仍然清楚。
- 不要在 Logo 中嵌入移动端无法辨认的标语或小号文字。
- 检查 Logo 是否具有合适的可访问名称或文字后备内容。

## Enter using password 链接

**Enter using password** 链接用于为获授权访客打开密码输入界面。它的显示文字通常通过主题语言翻译管理，而不是在当前面板中单独填写。

该分区不会创建或修改店面密码；密码保护应在 Shopify 的商店偏好设置中管理。请分别测试错误密码、正确密码、纯键盘操作和移动端交互。不要在页面文字、Custom CSS、截图或公开文档中暴露密码。

## Custom CSS（自定义 CSS）

仅在内置设置无法满足需求时，使用 **Custom CSS** 进行小范围的分区样式调整。应优先使用配色方案、间距和 Logo 设置；自定义选择器需要限定在当前分区内，并且不能隐藏密码链接、焦点指示或密码对话框控件。

## 发布前检查

1. 确认显示了正确的 Logo 或商店名称，并检查品牌区域和链接行为。
2. 检查页眉背景、文字、链接、悬停状态和焦点状态的对比度。
3. 检查桌面端和移动端布局，包括翻译后较长的链接文字。
4. 确认密码进入链接及相关对话框提示已完成翻译。
5. 分别使用鼠标、键盘和触控方式打开密码输入界面。
6. 测试错误和正确密码，同时确保密码不会暴露给未授权访客。
7. 检查页眉与 Password 主体分区的间距，避免出现过宽空白。
8. 保存主题后，在无痕窗口完成一次最终测试。
