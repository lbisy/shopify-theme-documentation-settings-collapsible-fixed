# 404 页面（Not found）

404 页面在访客打开不存在或已移除的页面地址时显示。**Not found** 分区用于配置错误提示、两行标题、返回按钮和装饰水印，帮助顾客继续浏览商店。

## 打开与配置

1. 进入 **Shopify 后台 → 在线商店 → 主题 → 自定义**。
2. 使用顶部页面选择器切换到 **404 页面**。
3. 在左侧模板区域选择 **Not found**。
4. 配置配色、标题、说明、按钮和水印文字。
5. 预览桌面端与移动端效果，点击 **保存**。

此分区用于 404 模板，请在对应模板中编辑。

## 配色（Color scheme）

选择 404 分区使用的全局配色方案。截图中第一行第二个配色缩略图被选中。

点击 **编辑方案** 可修改所选方案，其他使用同一方案的区域也会受到影响。请检查标题、正文、水印和按钮与背景之间的对比度。

## 标题与说明（Heading）

| 设置项 | 截图当前值 | 作用 |
| --- | --- | --- |
| **Heading size** | **3X large** | 设置错误页面标题的字号。 |
| **Heading line 1** | `404` | 设置标题第一行。 |
| **Heading line 2** | `Not Found` | 设置标题第二行。 |
| **Description** | 下方示例文案 | 在标题下方解释页面状态，并引导顾客继续浏览。 |

Heading size 可选 **Extra small、Small、Medium、Large、Extra large、2X large、3X large、4X large**。截图选择的 3X large 与安装包默认值一致。

两行标题分别编辑，均支持加粗、斜体和链接等行内格式。截图使用第一行 `404`、第二行 `Not Found`，与安装包默认文字一致。更改文字后，请检查移动端是否出现过多换行。

截图中的 Description 为：

> The page you're looking for has moved or no longer exists. Return home to continue exploring.

Description 支持富文本格式、段落和列表。建议清楚说明页面不可用，并提供简短的下一步指引。截图文案是当前配置，安装包默认提供的是另一段示例说明。

## 返回按钮

| 设置项 | 截图当前值 | 作用 |
| --- | --- | --- |
| **Show button** | **开启** | 控制是否显示返回按钮。 |
| **Button label** | `Back to Home` | 设置按钮上显示的文字。 |
| **Button link** | `/` | 设置按钮目标地址；`/` 表示商店首页。 |

这三项截图值与安装包默认值一致。若希望按钮进入其他页面，可更换 Button link，并同时修改 Button label，使文字与目标内容一致。

关闭 Show button 后，页面不显示此按钮。建议保留明确的继续浏览入口；设置完成后，在店铺预览中点击按钮，确认能够返回首页或进入预期页面。

## 水印文字（Watermark text）

截图中的 **Watermark text** 为 `Ceylune`，用于显示页面中的装饰性品牌文字。安装包默认文字为 `Your brand`，与截图配置不同。

建议使用简短品牌名，并检查水印在不同屏幕上不会干扰标题、说明或按钮的阅读。

## 上下间距（Padding）

| 设置项 | 截图当前值 | 作用 |
| --- | --- | --- |
| **Padding top** | `32 px` | 调整分区顶部留白。 |
| **Padding bottom** | `32 px` | 调整分区底部留白。 |

两项可通过滑块或数值输入框调整，范围均为 **0–100 px**，步长 **4 px**。截图与安装包默认值均为 `32 px`。

## 自定义 CSS

截图底部的 **自定义 CSS** 是主题编辑器提供的分区样式入口。优先使用已有配色、字号和间距设置；添加局部样式后，请检查桌面端与移动端的文字排版和按钮可见性。

## 保存并检查

- 标题第一行为 404，第二行为 Not Found，字号为 3X large。
- 说明文案清晰可读，移动端没有异常换行或遮挡。
- Show button 已开启，Back to Home 按钮能够跳转至 `/`。
- Ceylune 水印与主要内容之间有足够的视觉区分。
- 上下 `32 px` 留白与页眉、页脚协调。
- 保存后访问一个不存在的页面地址，检查实际 404 页面及返回操作。
