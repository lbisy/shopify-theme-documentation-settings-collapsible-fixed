# 商品系列导航加载组件（Collection nav items）

这是为商品系列导航分批加载列表的内部组件，输出商品系列名称、商品数量和链接。它没有独立的分区设置项。

## 打开与配置

1. 进入 Shopify 后台的 **在线商店 → 主题 → 自定义**。
2. 请在主题设置 → Collection navigation 中配置商品系列导航的相关选项。
3. 此组件未声明 presets，无需把它当作普通展示板块手动添加。
4. 完成后点击 **保存**，分别检查桌面端和移动端效果。

[查看商品系列导航设置](/zh/settings/collection-navigation)
