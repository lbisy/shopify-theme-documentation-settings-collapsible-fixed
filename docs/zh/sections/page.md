# Page（普通页面）

**Page** 模板用于展示“关于我们”、配送说明、尺码指南、常见问题和商店政策等 Shopify 普通页面。正确流程是先在 Shopify 后台创建并保存页面资源，再从主题编辑器顶部选择器的 **Pages** 中打开该页面，配置其模板布局。

页面内容与页面布局分别在两个位置管理：

- **Shopify 后台 → 在线商店 → 页面**：管理页面标题、正文、可见性、搜索引擎列表、URL handle 和分配的主题模板。
- **在线商店 → 主题 → 自定义**：管理所分配模板的布局和外观，包括模板中的分区以及主题提供的设置。

## 第一步：创建页面

1. 进入 **Shopify 后台 → 在线商店 → 页面**。
2. 点击 **添加页面 / Add page**。
3. 填写清晰的页面**标题**。
4. 在富文本**内容**编辑器中填写页面正文。
5. 在**可见性 / Visibility** 中选择立即发布、保持隐藏，或在界面支持时安排发布时间。
6. 在**在线商店 / Online store** 中选择 **Theme template（主题模板）**。页面不需要独立布局时使用默认 page 模板。
7. 根据需要检查搜索引擎列表和 URL handle。
8. 点击**保存**。

页面设为可见后不会自动出现在店铺导航中。如需让顾客通过页眉或页脚访问，请把已保存页面添加到对应菜单。

## 第二步：在主题编辑器中引用页面

1. 进入 **在线商店 → 主题**。
2. 找到需要编辑的主题，点击 **自定义**。
3. 点击编辑器顶部的页面选择器。刚打开编辑器时，此处通常显示 **Home page**。
4. 按下图所示选择 **Pages**。
5. 选择需要预览的页面或该页面所使用的模板；列表较长时可使用 **Search online store** 搜索。
6. 确认预览区显示的是目标页面标题和正文。
7. 在模板列表中点击 **Page**，查看当前主题版本提供的设置。
8. 根据需要添加、移除、隐藏或调整其他可用分区的顺序，然后点击**保存**。

![在主题编辑器的页面选择器中选择 Pages](/images/zh/page.png)

顶部选择器只是切换正在预览的页面资源或模板，不会把页面正文复制到主题编辑器中。Page 分区会自动读取当前页面资源。

## 页面内容

页面主标题和正文应在 Shopify 后台的页面记录中编辑，Page 分区负责将该资源显示到已分配的模板中。

编辑内容时建议：

- 使用一个明确的页面标题，并用含义清楚的小标题组织较长正文。
- 保持标题层级顺序合理，不要仅为了改变字号而随意选择标题级别。
- 使用能够说明目标的链接文字，避免只写“点击这里”。
- 为传递信息的图片填写替代文本；只有纯装饰图片才应留空。
- 不要把主题不支持的脚本、表单或复杂样式直接粘贴到富文本编辑器中。
- 在移动端检查表格、嵌入媒体和较长链接的显示效果。

修改页面标题或正文只影响当前页面；修改模板中的分区或布局，会影响所有使用同一模板的页面。

## Page 分区与模板布局

点击内置的 **Page** 分区，可以调整当前主题版本提供的外观设置。这些设置可能控制页面容器、配色方案、间距或分区样式，但页面标题和正文仍来自已保存的页面资源。

可以在 Page 分区前后添加其他主题分区，以组合更丰富的页面布局。需要显示后台页面标题和富文本正文时，请保持 Page 分区启用；如果将其隐藏或移除，页面记录仍然存在，但其主要内容不会出现在店铺模板中。

修改前应区分全局设置和模板设置。编辑共用配色方案可能影响其他模板，而添加分区或调整分区顺序会影响所有分配了当前页面模板的页面。

## 为独立布局创建专用模板

使用同一模板的页面会共享分区结构和模板设置。如果某个页面需要不同的首屏、分区顺序、间距或辅助内容，应创建专用页面模板，而不是直接修改共用的默认模板。

1. 在主题编辑器中打开顶部页面选择器，选择 **Pages**。
2. 点击 **Create template（创建模板）**。
3. 填写唯一的模板名称，并选择一个现有 page 模板作为基础。
4. 创建模板，调整其中的分区，然后点击**保存**。
5. 返回 **Shopify 后台 → 在线商店 → 页面**，打开目标页面。
6. 在 **在线商店 → Theme template** 中分配新模板并保存页面。
7. 返回主题编辑器，再次打开该页面进行预览。

::: warning 模板可用范围
页面记录中的 **Theme template** 列表以已发布主题中存在的模板为准。仅在未发布主题中创建的模板，可能要等该主题发布后才能在页面记录中分配。发布前可以继续在草稿主题中预览，并在发布过程中核对模板分配。
:::

## 可见性、网址与导航

以下设置彼此相关，但作用不同：

- **可见性**决定页面是否发布到在线商店。
- **URL handle** 决定页面地址，通常位于 `/pages/` 路径下。
- **Theme template** 决定页面布局。
- **菜单**决定顾客能否从店铺导航进入该页面。

因此，页面可以处于可见状态并能通过直接网址访问，但没有出现在任何菜单中。修改 URL handle 后，应检查外部链接、菜单、推广活动和重定向，避免旧链接进入 404 页面。

## 常见问题

- **页面选择器中找不到页面**：先保存页面，使用标题搜索，确认页面属于在线商店，然后重新加载主题编辑器。
- **预览显示了错误内容**：确认当前预览资源，以及该页面实际分配的模板。
- **调整布局后多个页面一起变化**：这些页面共用同一个模板；请为需要独立布局的页面创建并分配专用模板。
- **页面已经创建，但顾客找不到**：确认页面可见，并将它添加到合适的菜单。
- **标题或正文没有显示**：确认 Page 分区处于启用状态，并在后台页面记录中编辑内容，而不是只检查主题编辑器。
- **新模板没有出现在页面模板列表中**：确认创建的是 Page 类型模板，并且该模板存在于已发布主题中。

## 发布前检查

1. 确认页面资源与主题模板分配正确。
2. 检查标题、正文、链接、图片、替代文本、表格和嵌入媒体。
3. 预览所有使用当前模板的页面。
4. 检查桌面端和移动端的宽度、间距、文字对比度与标题层级。
5. 测试公开网址以及所有指向该页面的菜单链接。
6. 确认隐藏或定时发布页面不会提前公开。
7. 保存页面记录、菜单更改和主题自定义设置。

更多信息可参考 Shopify 的[创建页面](https://help.shopify.com/en/manual/online-store/add-edit-pages)和[模板使用说明](https://help.shopify.com/en/manual/online-store/themes/theme-structure/templates)。
