# 按钮（Button）

**Button** 设置用于统一控制商店按钮的间距、边框、圆角和阴影，包括**添加到购物车**、**立即购买**、**提交**和**了解更多**等按钮。

## 打开 Button 设置

1. 在 Shopify 后台进入**在线商店 > 主题**。
2. 找到需要编辑的主题，点击**自定义**。
3. 打开**主题设置 > Button**。

![Button 设置与店铺预览](/images/zh/settings/button.png)

上图使用了舒适的内边距、细边框、`8 px` 圆角，并关闭了阴影。

## 间距（Spacing）

间距控制按钮文字与按钮边缘之间的留白。

| 设置项 | 图中数值 | 作用 |
| --- | ---: | --- |
| **Button horizontal padding** | `24 px` | 控制文字左右两侧的空间。增大数值会让按钮更宽，减小数值会使布局更紧凑。 |
| **Button vertical padding** | `12 px` | 控制文字上下两侧的空间。增大数值会让按钮更高、更醒目，也能扩大触控区域。 |

调整后应检查较长的按钮文字，以及同一行放置多个按钮的布局。移动端需要保留足够的垂直内边距，确保按钮容易点击。

## 边框（Border）

边框设置控制按钮轮廓和圆角形状。

| 设置项 | 图中数值 | 作用 |
| --- | ---: | --- |
| **Button border thickness** | `1 px` | 控制轮廓宽度。设置为 `0 px` 时不显示边框。 |
| **Button radius** | `8 px` | 控制圆角大小。较小的数值更利落，较大的数值更柔和、圆润。 |

按钮边框颜色来自**主题设置 > Colors** 中当前使用的配色方案。为了保持界面统一，建议同时协调输入框、对话框、商品卡片和其他交互元素的圆角。

## 阴影（Shadow）

阴影可以让按钮呈现悬浮于页面之上的立体效果。

| 设置项 | 图中数值 | 作用 |
| --- | ---: | --- |
| **Button shadow opacity** | `0%` | 控制阴影可见度。设置为 `0%` 时关闭阴影。 |
| **Button shadow horizontal offset** | `0 px` | 正值使阴影向右移动，负值使阴影向左移动。 |
| **Button shadow vertical offset** | `0 px` | 正值使阴影向下移动，负值使阴影向上移动。 |
| **Button shadow blur** | `0 px` | 控制阴影边缘的柔和程度。数值越大，阴影越柔和。 |

应先设置阴影不透明度。不透明度为 `0%` 时，偏移量和模糊度不会产生可见效果。如需添加阴影，建议从较低的不透明度和较小的偏移量开始，并在浅色、深色背景上分别预览。

## 颜色与焦点状态

按钮尺寸和外形在本页面配置，按钮颜色则在**主题设置 > Colors** 中配置：

- **Primary button background color**、**label color** 和 **border color**
- **Secondary button background color**、**label color** 和 **border color**

请确保所有配色方案中的按钮文字都有足够的对比度。同时检查键盘焦点环是否清晰可见，且不会被按钮边框或阴影遮挡。

## 推荐调整顺序

1. 设置水平和垂直内边距。
2. 调整边框粗细和圆角。
3. 确定设计是否需要阴影。
4. 检查主按钮和次要按钮的颜色。
5. 预览悬停、焦点和禁用状态。
6. 分别检查桌面端和移动端效果。

截图中的数值（`24 px`、`12 px`、`1 px`、`8 px` 和无阴影）适合作为简洁、扁平按钮样式的均衡起点。

## 保存并测试

点击**保存**，然后检查：

- 主按钮和次要按钮的样式是否协调一致。
- 较长的按钮文字是否完整显示，且没有不自然的换行。
- 移动端按钮是否容易点击、是否超出屏幕宽度。
- 边框在浅色和深色配色方案中是否清晰可见。
- 悬停、焦点和禁用状态是否容易区分。
- 添加到购物车、结账和表单提交等关键操作是否正常。
