# 输入框（Input）

**Input** 设置用于统一控制搜索框、联系表单、邮件订阅、顾客信息和其他文字输入控件的内边距、边框、圆角与阴影。

## 打开 Input 设置

1. 登录 Shopify 后台，进入 **在线商店 > 主题**。
2. 找到当前主题，点击 **自定义**。
3. 打开 **主题设置 > Input**。

![Input 设置与店铺预览](/images/zh/settings/input.png)

截图中的输入框使用舒适的内边距、细边框和中等圆角，并且关闭了阴影，整体风格简洁清晰。

## 间距（Spacing）

Spacing 控制输入内容与输入框边缘之间的空间。

| 设置项 | 作用 | 截图中的值 |
| --- | --- | --- |
| **Input horizontal padding** | 文字和图标左右两侧的空间 | `16 px` |
| **Input vertical padding** | 内容上下方的空间，同时影响输入框高度 | `12 px` |

增加水平内边距可以让输入框更宽松，但应检查较长的占位文字以及带前置、后置图标的字段。垂直内边距需要为移动端提供舒适的触控区域，同时避免让紧凑表单显得过高。

## 边框（Border）

Border 设置控制输入框轮廓与四角形状。

| 设置项 | 作用 | 截图中的值 |
| --- | --- | --- |
| **Input border thickness** | 输入框轮廓宽度 | `1 px` |
| **Input radius** | 四个角的圆润程度 | `8 px` |

`1 px` 边框可以清晰区分输入框与背景，同时不会显得厚重。`8 px` 圆角形成适度圆润的外观。建议让输入框圆角与按钮、对话框的设计保持协调，使表单风格一致。

边框颜色需要在 **主题设置 > Colors > Input border** 中单独配置。

## 阴影（Shadow）

Shadow 设置控制输入框周围的层次效果。

| 设置项 | 作用 | 截图中的值 |
| --- | --- | --- |
| **Input shadow opacity** | 阴影整体可见程度 | `0%` |
| **Input shadow horizontal offset** | 让阴影向左或向右移动 | `0 px` |
| **Input shadow vertical offset** | 让阴影向上或向下移动 | `0 px` |
| **Input shadow blur** | 控制阴影边缘的柔和程度 | `0 px` |

透明度为 `0%` 时，阴影处于关闭状态，偏移和模糊值不会产生可见效果。如果需要添加阴影，建议先设置较低透明度，再调整偏移和模糊。避免使用过重的阴影，以免输入框看起来像按钮。

## 颜色与焦点

本页面用于设置输入框结构，其他视觉状态需要在相应设置中调整：

- **主题设置 > Colors**：Input text、Input background、Input border 和 Input placeholder。
- **主题设置 > Focus**：焦点轮廓宽度与偏移。

::: info 可访问性
占位文字不能替代清晰可见的字段标签。请保证输入文字、占位文字、边框和背景之间具有足够对比度，并让键盘焦点轮廓始终可见。
:::

## 推荐调整顺序

1. 设置水平和垂直内边距。
2. 选择边框厚度与圆角。
3. 确认设计是否需要阴影。
4. 在当前配色方案中设置输入框颜色。
5. 检查键盘焦点和验证状态。
6. 在桌面端和移动端预览表单。

截图中的数值适合作为简洁表单风格的平衡起点。需要更柔和的效果时，可以增大圆角；需要轻微悬浮感时，可以添加低透明度的模糊阴影。

## 保存并测试

点击 **保存**，然后检查：

- 搜索、联系、订阅、顾客和结账相关输入框是否保持一致。
- 占位文字和已输入文字是否完整显示。
- 移动端输入框高度是否便于点击。
- 图标是否会遮挡较长文字。
- 输入框边框在浅色和深色方案中是否清晰。
- 使用 `Tab` 键时是否显示明确的焦点轮廓。
- 错误、自动填充、禁用和完成状态是否容易理解。

最后实际提交有代表性的表单，确认输入、清除、自动填充、验证和错误处理都能正常工作。
