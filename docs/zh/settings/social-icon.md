# 社交图标（Social icon）

**Social icon** 设置用于添加商店的社交平台主页链接。当主题中支持社交链接的区域显示这些内容时，每个已填写字段会生成对应的平台图标。

## 打开 Social icon 设置

1. 在 Shopify 后台进入**在线商店 > 主题**。
2. 找到需要编辑的主题，点击**自定义**。
3. 打开**主题设置 > Social icon**。

![Social icon 设置与店铺预览](/images/zh/settings/social-icon.png)

截图中包含 9 个平台字段。`1`、`2`、`3` 是不完整的占位内容，发布前需要替换。

## 社交平台字段

| 平台 | 图中内容 | 检查说明 |
| --- | --- | --- |
| **Facebook** | `1` | 不完整；需要替换为完整的 Facebook 主页网址。 |
| **Instagram** | `2` | 不完整；需要替换为完整的 Instagram 主页网址。 |
| **YouTube** | `3` | 不完整；需要替换为完整的 YouTube 频道网址。 |
| **TikTok** | `https://tiktok.com/@shopify` | 完整网址格式，需要替换为自己的主页。 |
| **X / Twitter** | `https://x.com/shopify` | 完整网址格式，需要替换为自己的主页。 |
| **Snapchat** | `https://www.snapchat.com/add/shopify` | 完整网址格式，需要替换为自己的主页。 |
| **Pinterest** | `https://pinterest.com/shopify` | 完整网址格式，需要替换为自己的主页。 |
| **Tumblr** | `https://shopify.tumblr.com` | 完整网址格式，需要替换为自己的主页。 |
| **Vimeo** | `https://vimeo.com/shopify` | 完整网址格式，需要替换为自己的主页。 |

只保留属于商店或品牌的主页链接。不使用的平台应保持为空，以免显示对应图标。

## 填写有效主页链接

在每个字段中粘贴完整的公开主页或频道网址：

- 网址应以 `https://` 开头。
- 应填写主页网址，而不是只有用户名、账号或数字占位符。
- 保存前在浏览器中打开网址，确认能够进入预期的公开主页。
- 移除追踪参数或临时登录链接。
- 检查大小写和准确的账号名称。

例如，应将 `1`、`2`、`3` 分别替换为类似 `https://www.facebook.com/yourbrand`、`https://www.instagram.com/yourbrand` 和 `https://www.youtube.com/@yourbrand` 的地址。

## 显示位置与外观

社交图标只会出现在主题支持它们的分区中，例如页眉、页脚或社交媒体区块。如果已经保存有效链接但没有看到图标，请确认相关分区已经启用社交图标，并且该位置支持对应平台。

图标尺寸、颜色、间距以及悬停或焦点样式可能取决于所在分区和当前配色方案。请分别检查桌面端和移动端中所有显示社交链接的位置。

## 无障碍与维护

使用鼠标和键盘分别测试图标。每个图标都应具有可见的焦点标识，以及能够识别平台名称的无障碍名称。还应确认打开外部主页后，顾客能够方便地返回商店。

社交账号名称和网址可能发生变化。应定期检查链接，并在主页更名、迁移或停止使用时立即更新。

## 推荐操作顺序

1. 删除占位内容和不使用平台的链接。
2. 粘贴每个平台完整的 `https://` 主页网址。
3. 打开每个网址并确认目标页面。
4. 保存主题设置。
5. 检查所有支持社交图标的页眉、页脚或社交分区。
6. 测试桌面端、移动端、键盘焦点和链接行为。

## 保存并测试

点击**保存**，然后确认：

- 每个已填写字段显示正确的平台图标。
- 每个图标都能打开预期的品牌公开主页。
- 未填写的平台不会显示。
- 所有字段中都没有只有用户名或数字占位内容的情况。
- 图标在每个配色方案中都清晰可见、间距正确。
- 移动端可以正常操作，键盘焦点清晰，链接具备无障碍支持。
