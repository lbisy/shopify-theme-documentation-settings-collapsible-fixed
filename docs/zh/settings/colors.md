# 颜色（Colors）

**Colors** 设置用于创建可重复使用的店铺配色方案。每套方案可以统一定义背景、文字、边框、输入框、按钮、徽章和反馈消息的颜色。修改某套方案后，所有使用该方案的区块都会同步更新。

## 打开 Colors 设置

1. 登录 Shopify 后台，进入 **在线商店 > 主题**。
2. 找到当前主题，点击 **自定义**。
3. 打开 **主题设置 > Colors**。
4. 选择需要修改的配色方案，然后点击 **Edit scheme**。

![配色方案与店铺预览](/images/zh/settings/colors.png)

::: warning 共享修改
修改配色方案会影响所有正在使用该方案的区块。大幅调整颜色前，请先确认该方案被应用在哪些位置。
:::

## 管理配色方案

方案卡片用于为店铺不同区域提供可重复使用的配色。需要独立视觉风格时，可以点击 **Add Scheme** 新建方案。

**Page background color scheme** 用于设置区块背后以及未单独指定配色方案区域的页面背景。支持配色方案的区块可以在区块设置中选择其他方案。

建议保持少量、用途明确的方案。例如，可以分别创建浅色内容方案、深色品牌方案和促销区域使用的强调色方案。

## 通用颜色（General colors）

General colors 决定当前方案的基础外观。后三张图中的 Scheme 3 使用以下值：

| 设置项 | 作用 | 截图中的值 |
| --- | --- | --- |
| **Background** | 当前方案的基础背景色 | `#1B2900` |
| **Background gradient** | 可选渐变；在支持的位置替代纯色背景 | `No color chosen` |
| **Text color** | 主要标题、正文和支持该颜色的图标 | `#D5FF83` |
| **Border color** | 分隔线、轮廓和组件边框 | `#111827` |
| **Focus ring color** | 键盘操作时交互控件的焦点轮廓 | `#1D4ED8` |

::: warning 背景渐变
选择渐变后，适用位置会使用 **Background gradient** 替代 **Background** 纯色。清除渐变后才会恢复纯色背景。
:::

背景与文字之间应保持足够的对比度。焦点轮廓也必须清晰可见，方便键盘用户识别当前选中的链接、按钮或输入框。

## 输入框（Inputs）

输入框颜色适用于搜索框、联系表单、邮件订阅表单和其他文字输入字段。

| 设置项 | 作用 | 截图中的值 |
| --- | --- | --- |
| **Input text** | 用户输入内容的文字颜色 | `#151515` |
| **Input background** | 输入框背景色 | `#FFFFFF` |
| **Input border** | 输入框默认边框颜色 | `#D6D6D6` |
| **Input placeholder** | 输入前显示的占位提示文字 | `#717171` |

占位文字应与已输入文字有所区别，同时仍需清晰可读。建议检查输入框的默认、聚焦、已填写、验证错误和禁用状态。

## 主按钮（Primary button）

主按钮用于页面中最重要的操作，例如 **添加到购物车**、**立即购买** 或 **提交**。

| 设置项 | 截图中的值 |
| --- | --- |
| **Primary button background color** | `#F9FAFB` |
| **Primary button label color** | `#111827` |
| **Primary button border color** | `#F9FAFB` |

主按钮应在当前方案中足够醒目，同时保证按钮文字易于阅读。

## 次要按钮（Secondary button）

次要按钮用于优先级较低的操作，例如 **了解更多**、**继续购物** 或 **返回**。

| 设置项 | 截图中的值 |
| --- | --- |
| **Secondary button background color** | `Transparent` |
| **Secondary button label color** | `#FFFFFF` |
| **Secondary button border color** | `#F9FAFB` |

透明背景会形成描边按钮。请检查按钮文字和边框在方案使用的每一种背景上是否清晰，尤其是带图片背景的区块。

## 徽章（Badges）

徽章用于显示促销、新品、售罄等紧凑的商品或状态标签。

| 设置项 | 截图中的值 |
| --- | --- |
| **Badge background color** | `#1D4ED8` |
| **Badge label color** | `#FFFFFF` |
| **Badge border color** | `#1D4ED8` |

徽章显示面积较小，应使用简洁、高对比度的配色，并在商品图片和卡片背景附近检查实际效果。

## 反馈消息（Feedback messages）

每种反馈状态都包含背景色和前景色。前景色通常用于文字、图标和相关轮廓。

| 状态 | 背景色 | 前景色 | 常见用途 |
| --- | --- | --- | --- |
| **Success** | `#ECFDF5` | `#065F46` | 操作完成和表单提交成功 |
| **Warning** | `#FFFBEB` | `#92400E` | 需要用户注意的信息 |
| **Error** | `#FEF2F2` | `#991B1B` | 操作失败、字段无效或阻断性问题 |
| **Info** | `#F4F4F5` | `#27272A` | 一般通知和补充说明 |

::: info 可访问性
不要只依靠颜色表达状态。请保留清晰的文字标签和状态图标，使成功、警告、错误和信息消息对所有访客都容易理解。
:::

## 删除配色方案

**Remove color scheme** 用于删除当前正在编辑的方案。删除前请：

1. 确认哪些区块正在使用该方案。
2. 为这些区块指定替代方案。
3. 记录以后可能需要的颜色值。

删除操作可能无法直接恢复，因此应在确认所有依赖关系后再移除方案。

## 推荐设置流程

1. 根据明确用途选择或新建配色方案。
2. 先设置背景色和文字颜色。
3. 配置边框和焦点轮廓。
4. 设置输入框、主按钮、次要按钮和徽章。
5. 完成四种反馈消息的颜色设置。
6. 在桌面端和移动端预览有代表性的区块。
7. 检查对比度与组件状态后，点击 **保存**。

十六进制颜色值可以在不同方案之间复制，以保持品牌颜色一致。保存后，请在方案使用的所有位置检查文字、链接、按钮、输入框、徽章、反馈消息、焦点轮廓和渐变效果。
