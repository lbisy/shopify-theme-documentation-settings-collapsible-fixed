# 焦点（Focus）

**Focus** 设置用于控制键盘导航时显示的焦点环。焦点环可以标示当前接收键盘输入的链接、按钮、输入框或其他交互元素。

## 打开 Focus 设置

1. 在 Shopify 后台进入**在线商店 > 主题**。
2. 找到需要编辑的主题，点击**自定义**。
3. 打开**主题设置 > Focus**。

![Focus 设置与店铺预览](/images/zh/settings/focus.png)

上图使用 `2 px` 宽的焦点环，并在焦点环和当前元素之间保留 `2 px` 间距。

## 焦点环设置

| 设置项 | 图中数值 | 作用 |
| --- | ---: | --- |
| **Focus ring width** | `2 px` | 控制焦点标识的粗细。较大的数值更醒目，过小的数值可能在复杂背景上难以识别。 |
| **Focus ring offset** | `2 px` | 控制焦点环与元素边缘之间的距离。少量间距有助于将焦点环与边框、轮廓区分开。 |

`2 px` 宽度和 `2 px` 偏移适合作为大多数界面的清晰、紧凑起点。

## 宽度与偏移建议

不要将 **Focus ring width** 减小到 `0 px`。移除可见焦点标识后，键盘用户将无法判断当前正在操作哪个控件。

偏移量需要足以让焦点环与按钮、输入框、卡片和图片边框区分开。偏移过大时，焦点环可能与附近文字或控件重叠；偏移过小时，则可能与元素轮廓混在一起。还应检查圆角元素能否完整显示焦点环，而不会被裁切。

## 焦点环颜色

焦点环颜色需要在**主题设置 > Colors > [配色方案] > Focus ring color** 中单独配置。宽度和偏移是全局设置，颜色则属于各个配色方案。

选择的颜色应当：

- 与周围背景形成明显对比。
- 与元素自身的边框和填充颜色容易区分。
- 在浅色、深色、图片和强调色背景上保持可见。
- 在整个商店中能够被识别为同一种焦点状态。

修改宽度、偏移或焦点环颜色后，需要检查每个配色方案。

## 需要测试的元素

使用 `Tab` 向前移动，使用 `Shift + Tab` 向后移动，并检查：

- 页眉导航、搜索、账户、语言和购物车控件
- 商品卡片、商品选项、数量控件和购买按钮
- 表单、选择器、复选框和链接
- 购物车抽屉、对话框、覆盖层和关闭控件
- 页脚链接和社交图标

当前元素应始终具有完整、无遮挡的焦点标识。按下适用的激活键，例如 `Enter` 或 `Space`，确认每个控件仍能正常工作。

## 推荐调整顺序

1. 设置清晰可见的焦点环宽度。
2. 添加足以区分元素边框的偏移量。
3. 在每个配色方案中配置焦点环颜色。
4. 测试向前和向后的键盘导航。
5. 检查浅色、深色、图片和高对比背景。
6. 检查桌面端和较窄的移动端布局。

## 保存并测试

点击**保存**，然后确认：

- 每个交互元素获得焦点时都有可见标识。
- 焦点环不会被卡片、对话框、抽屉或容器裁切。
- 在较高的浏览器缩放比例下，宽度和偏移仍然清晰。
- 焦点环颜色在每个启用的配色方案中都清晰可见。
- 焦点顺序与视觉顺序和阅读顺序一致。
- 打开和关闭覆盖层后，焦点会返回合理位置。

焦点可见性应优先于装饰样式。不要仅因为焦点环改变了组件外观就将其隐藏。
