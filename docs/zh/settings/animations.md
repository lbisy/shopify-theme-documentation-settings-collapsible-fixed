# 动画（Animations）

**Animations** 设置用于控制内容和媒体进入视口时的展示方式。适当的动态效果可以引导注意力、增强页面节奏；过多或反复播放的动画则可能分散注意力，或让页面显得响应较慢。

## 打开 Animations 设置

1. 在 Shopify 后台进入**在线商店 > 主题**。
2. 找到需要编辑的主题，点击**自定义**。
3. 打开**主题设置 > Animations**。

![Animations 设置与店铺预览](/images/zh/settings/animations.png)

上图已开启动画，内容使用 **Rise**，媒体使用 **Zoom**，速度为 **Normal**，并在元素重新进入视口时再次播放动画。

## 动画设置

| 设置项 | 图中数值 | 作用 |
| --- | ---: | --- |
| **Enable motion** | **开启** | 页面出现动画的总开关。关闭后，内容会立即显示。 |
| **Content reveal style** | **Rise** | 控制标题、文字、按钮和其他内容的出现方式。**Rise** 会在淡入时轻微向上移动。 |
| **Media reveal style** | **Zoom** | 控制图片、视频和其他媒体的出现方式。**Zoom** 会在淡入时轻微缩放。 |
| **Motion speed** | **Normal** | 控制整体出现动画的速度，可选择 **Slow**、**Normal** 或 **Fast**。 |
| **Reveal behavior** | **Replay on re-enter** | 元素离开视口后再次进入时，重新播放出现动画。 |

关闭 **Enable motion** 只会阻止出现动画延迟内容，不会隐藏页面内容。

## 内容与媒体展示样式

内容和媒体可以分别设置，以便在同一页面使用不同程度的视觉强调。

- **None**：元素立即显示，不使用出现效果。
- **Fade**：逐渐改变透明度，通常是干扰较少的动画选项。
- **Rise**：内容淡入时轻微向上移动。
- **Zoom**：媒体淡入时进行轻微缩放。

截图中的组合使用 **Rise** 展示内容、使用 **Zoom** 展示媒体，整体效果更有表现力。应重点预览图片较多的分区、商品网格、轮播图和大幅横幅，因为大量同时播放的缩放效果可能争夺注意力。

## 速度与重复行为

- **Slow**：节奏舒缓、强调氛围，但元素需要更长时间才能达到最终状态。
- **Normal**：在动态效果和响应速度之间保持平衡，适合大多数商店。
- **Fast**：更快完成出现动画，适合内容较密集的页面。

**Reveal behavior** 可选择：

- **Once**：元素第一次进入视口时播放一次出现动画。
- **Replay on re-enter**：元素每次重新进入视口时再次播放动画。

内容较长的页面、商品网格和重视阅读的布局建议使用 **Once**。只有在重复动态效果符合设计意图且不会干扰浏览时，才使用 **Replay on re-enter**。

## 减少动态效果与性能

当访客通过设备或浏览器请求减少动态效果时，内容应立即显示。关闭页面动画后，内容也应立即出现。

请在真实移动设备和图片较多的页面上测试性能，检查首屏内容延迟、滚动卡顿、布局跳动及多个分区同时播放动画等情况。动态效果应服务于内容，而不是让界面显得更慢。

## 推荐调整顺序

1. 开启动画并选择内容展示样式。
2. 为媒体选择独立的展示样式。
3. 设置保持响应感的动画速度。
4. 决定动画只播放一次，还是在重新进入视口时重复播放。
5. 预览长页面、密集的商品网格和移动端布局。
6. 开启减少动态效果偏好进行测试。

截图中的设置（**Rise**、**Zoom**、**Normal** 和 **Replay on re-enter**）会形成明显且可重复的动态风格。如需更安静的页面，可以将行为改为 **Once**，或为内容、媒体中的一项或两项选择 **Fade**。

## 保存并测试

点击**保存**，然后检查：

- 首屏内容是否及时显示。
- 文字、按钮、图片和视频是否流畅出现。
- 滚动商品网格时是否出现卡顿。
- 来回滚动时，重复动画是否分散注意力。
- 移动端滚动是否保持流畅。
- 键盘焦点是否不会被动画移动或遮挡。
- 减少动态效果模式和关闭动画时，所有内容是否立即可见。
