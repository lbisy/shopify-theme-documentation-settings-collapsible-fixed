# 文字排版（Typography）

**Typography** 设置用于统一管理商店的字体、文字层级、字间距和整体缩放。调整时应同时观察右侧店铺预览，确保标题与正文在桌面端和移动端都保持清晰、一致。

## 打开 Typography 设置

1. 登录 Shopify 后台，进入 **在线商店 > 主题**。
2. 找到当前主题，点击 **自定义**。
3. 打开 **主题设置 > Typography**。

![Typography 设置与店铺预览](/images/zh/settings/typography.png)

::: tip 实时预览
调整排版时保持右侧预览可见，并使用桌面端和移动端预览按钮检查换行、间距与可读性，确认后再保存。
:::

## 字体

分别选择标题和正文使用的基础字体。截图中的标题与正文均使用 **Inter**。

| 设置项 | 作用范围 | 截图中的值 |
| --- | --- | --- |
| **Heading > Font** | 页面标题、区块标题、商品标题和其他醒目文字 | `Inter` |
| **Body > Font** | 段落、导航、按钮、标签和商品信息 | `Inter` |

标题与正文使用同一种字体可以形成简洁、统一的视觉效果；如果需要更强的层次感，可以为标题选择更有个性的字体，为正文选择更易阅读的字体。商店包含中文内容时，请确认所选字体支持中文字符，或能够自然回退到兼容的系统字体。

## 标题（Heading）

**Heading** 组用于控制全站主要标题的显示样式。

| 设置项 | 作用 | 截图中的值 |
| --- | --- | --- |
| **Weight** | 控制笔画粗细和视觉强调程度 | `Bold` |
| **Line height** | 控制多行标题之间的垂直距离 | `1.2` |
| **Letter spacing** | 控制标题字符之间的距离 | `Slightly tight` |
| **Text transform** | 控制英文自动大写、小写或首字母格式 | `None` |

粗体与稍紧的字间距适合较大的编辑式标题。修改后应重点检查较长的商品名称和多行主视觉标题，避免文字过于拥挤或出现不自然的换行。

## 副标题（Subtitle）

**Subtitle** 组用于设置辅助标题和简短引导文字。

| 设置项 | 作用 | 截图中的值 |
| --- | --- | --- |
| **Font family** | 选择使用标题字体或正文字体 | `Heading font` |
| **Weight** | 控制副标题的强调程度 | `Medium` |
| **Line height** | 控制多行副标题的垂直间距 | `1.4` |
| **Letter spacing** | 控制副标题字符之间的距离 | `Normal` |
| **Text transform** | 控制英文自动大小写格式 | `None` |

副标题应明显弱于主标题，但仍需具备足够的识别度来引导区块内容。避免让副标题与主标题使用完全相同的字重和缩放比例。

## 正文（Body）

**Body** 组用于控制段落和辅助界面文字的基础字号与间距。

| 设置项 | 作用 | 截图中的值 |
| --- | --- | --- |
| **Font size (desktop)** | 桌面端基础正文字号 | `16 px` |
| **Font size (mobile)** | 移动端基础正文字号 | `14 px` |
| **Line height** | 控制正文行与行之间的垂直距离 | `1.6` |
| **Letter spacing** | 控制正文字符之间的距离 | `Normal` |
| **Text transform** | 控制英文自动大小写格式 | `None` |

桌面端和移动端字号可以独立调整。商品描述、博客文章、政策页面等长内容应保持舒适的阅读体验。不建议对整段正文应用全大写；如有需要，可仅用于较短的标签文字。

## 缩放（Scale）

基础设置完成后，可以使用 Scale 按比例统一调整标题和正文系统的大小。

| 设置项 | 作用 | 截图中的值 |
| --- | --- | --- |
| **Heading scale** | 调整所有标题的整体大小 | `100%` |
| **Body scale** | 调整正文及相关文字的整体大小 | `100%` |

`100%` 表示保留主题默认比例。建议先确定字体、基础字号、字重和行高，再调整缩放比例，避免多项设置叠加后导致文字意外过大或过小。

## 推荐调整顺序

1. 选择标题字体与正文字体。
2. 设置标题的字重、行高、字间距和大小写格式。
3. 配置副标题层级。
4. 设置桌面端和移动端正文字号。
5. 微调标题与正文缩放比例。
6. 在桌面端和移动端预览中检查代表性页面。

::: info 参考起点
截图中的数值可作为平衡的起点，但不是必须保持的固定值。请根据所选字体、品牌风格和实际内容量进行调整。
:::

## 保存并检查

点击 **保存**，然后检查：

- 页面标题、区块标题、副标题和正文之间是否具有清晰层级。
- 较长标题换行后是否整齐，且不会覆盖附近内容。
- 商品描述和文章正文是否易于连续阅读。
- 导航、按钮和商品卡片标签是否完整显示。
- 桌面端与移动端字号是否都协调。
- 中文与英文字符是否都能使用所选字体正常显示。
