# 对话框（Dialog）

**Dialog** 设置用于统一控制弹窗类界面的边框、圆角和阴影，包括快速查看窗口、搜索弹层、邮件订阅弹窗和其他对话框。具体受影响的组件取决于主题中启用的功能。

## 打开 Dialog 设置

1. 在 Shopify 后台进入**在线商店 > 主题**。
2. 找到需要编辑的主题，点击**自定义**。
3. 打开**主题设置 > Dialog**。

![Dialog 设置与店铺预览](/images/zh/settings/dialog.png)

上图隐藏了对话框边框，使用 `12 px` 圆角，并添加了略微向下偏移的柔和阴影。

## 边框（Border）

边框设置控制对话框轮廓和圆角形状。

| 设置项 | 图中数值 | 作用 |
| --- | ---: | --- |
| **Dialog border thickness** | `0 px` | 控制对话框轮廓宽度。设置为 `0 px` 时不显示边框。 |
| **Dialog radius** | `12 px` | 控制对话框圆角大小。较小的数值更利落，较大的数值更柔和、圆润。 |

关闭边框后，需要通过足够的颜色对比或阴影将对话框与页面区分开。边框颜色来自当前使用的配色方案。建议同时协调按钮、输入框、商品卡片和其他界面元素的圆角，使整体视觉风格保持一致。

## 阴影（Shadow）

阴影设置可以让对话框呈现浮在页面内容上方的效果。

| 设置项 | 图中数值 | 作用 |
| --- | ---: | --- |
| **Dialog shadow opacity** | `10%` | 控制阴影可见度。设置为 `0%` 时关闭阴影。 |
| **Dialog shadow horizontal offset** | `0 px` | 正值使阴影向右移动，负值使阴影向左移动。 |
| **Dialog shadow vertical offset** | `8 px` | 正值使阴影向下移动，负值使阴影向上移动。 |
| **Dialog shadow blur** | `24 px` | 控制阴影边缘的柔和程度和扩散范围。数值越大，阴影越柔和、范围越宽。 |

应先设置阴影不透明度，再调整偏移量和模糊度。截图中的数值会形成居中、轻柔的悬浮效果：较低的不透明度让阴影保持克制，`0 px` 水平偏移保持视觉平衡，向下偏移则增加层次感。

避免使用过深或范围过大的阴影，否则页面可能显得沉重，并可能遮挡附近内容，尤其是在较小的屏幕上。

## 视觉一致性与无障碍

对话框背景、文字和边框颜色通常跟随当前使用的配色方案。请检查对话框在浅色和深色页面背景上是否都能清楚区分，并确保标题、正文、输入框、按钮和关闭图标具有足够的颜色对比度。

外观设置不能替代交互测试。请确认：

- 对话框打开时，键盘焦点会进入对话框。
- 对话框打开期间，焦点清晰可见并保持在对话框内部。
- 关闭控件容易识别和操作。
- 关闭后，焦点会返回到打开对话框的元素。

## 推荐调整顺序

1. 设置边框粗细和圆角。
2. 设置阴影不透明度。
3. 调整水平和垂直偏移量。
4. 微调阴影模糊度。
5. 检查当前配色方案和页面遮罩。
6. 在桌面端和移动端预览每一种对话框。

截图中的数值（`0 px`、`12 px`、`10%`、`0 px`、`8 px` 和 `24 px`）适合作为简洁、轻柔悬浮对话框样式的均衡起点。

## 保存并测试

点击**保存**，然后打开商店中使用的每一种对话框并检查：

- 不使用边框时，对话框是否仍能与页面清楚区分。
- 圆角和阴影是否被裁切。
- 对话框是否完整显示在桌面端和移动端屏幕内。
- 标题、文字、输入框、按钮和关闭图标是否清晰、易用。
- 浅色和深色配色方案是否都具有足够的对比度。
- 打开、关闭、提交、取消和键盘操作是否正常。
