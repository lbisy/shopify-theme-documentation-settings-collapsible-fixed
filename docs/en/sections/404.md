# 404 Page (Not found)

The 404 page appears when a visitor opens a page address that does not exist or has been removed. The **Not found** section configures the error message, two-line heading, return button and decorative watermark to help customers continue browsing.

## Open and configure the section

1. Go to **Shopify admin → Online Store → Themes → Customize**.
2. Use the page selector at the top to open the **404 page**.
3. Select **Not found** in the template area of the left sidebar.
4. Configure the color scheme, heading, description, button and watermark.
5. Preview desktop and mobile, then click **Save**.

This section belongs to the 404 template; edit it within that template.

## Color scheme

Choose the global color scheme for the 404 section. The screenshot selects the second scheme thumbnail in the first row.

Click **Edit scheme** to change the selected scheme. Changes also affect other areas using it. Check heading, body text, watermark and button contrast against the background.

## Heading and description

| Setting | Current screenshot value | Purpose |
| --- | --- | --- |
| **Heading size** | **3X large** | Sets the error page heading size. |
| **Heading line 1** | `404` | Sets the first heading line. |
| **Heading line 2** | `Not Found` | Sets the second heading line. |
| **Description** | Example copy below | Explains the page status and guides customers back to browsing. |

Heading size offers **Extra small, Small, Medium, Large, Extra large, 2X large, 3X large and 4X large**. The screenshot's 3X large matches the package default.

Edit the two heading lines independently. Both support inline formatting such as bold, italic and links. The screenshot uses `404` and `Not Found`, matching the package defaults. After changing the wording, check for excessive wrapping on mobile.

The screenshot's Description reads:

> The page you're looking for has moved or no longer exists. Return home to continue exploring.

Description supports rich-text formatting, paragraphs and lists. Briefly explain that the page is unavailable and suggest a next step. This copy records the current screenshot configuration; the package supplies different sample text by default.

## Return button

| Setting | Current screenshot value | Purpose |
| --- | --- | --- |
| **Show button** | **Enabled** | Controls whether the return button is displayed. |
| **Button label** | `Back to Home` | Sets the visible button text. |
| **Button link** | `/` | Sets the destination; `/` opens the store homepage. |

All three screenshot values match the package defaults. To send visitors elsewhere, change Button link and update Button label to describe the destination.

Disabling Show button hides this button. Keep a clear way for customers to continue browsing. Test the button in the storefront preview to confirm that it opens the homepage or your intended destination.

## Watermark text

The screenshot sets **Watermark text** to `Ceylune`, providing decorative brand text on the page. The package default is `Your brand`, which differs from the screenshot configuration.

Use a short brand name and check that the watermark does not interfere with the heading, description or button at different screen sizes.

## Padding

| Setting | Current screenshot value | Purpose |
| --- | --- | --- |
| **Padding top** | `32 px` | Adjusts space above the section content. |
| **Padding bottom** | `32 px` | Adjusts space below the section content. |

Use the sliders or numeric inputs to adjust either value from **0–100 px**, in **4 px** steps. Both screenshot values match the package defaults of `32 px`.

## Custom CSS

The **Custom CSS** panel at the bottom of the screenshot is a section styling control provided by the theme editor. Use the existing color, size and spacing settings first. After adding local styles, check text layout and button visibility on desktop and mobile.

## Save and check

- Confirm the heading reads 404 on the first line and Not Found on the second, at 3X large.
- Check description readability and mobile wrapping without overlap.
- Keep Show button enabled and confirm Back to Home links to `/`.
- Ensure the Ceylune watermark remains visually separate from the primary content.
- Review the `32 px` top and bottom padding alongside the header and footer.
- After saving, visit a nonexistent page address and test the actual 404 page and return action.
