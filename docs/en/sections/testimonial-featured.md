# Featured testimonial

Featured testimonial arranges review cards in two scrolling rows, combining images, quotes, star ratings and author names. Section settings control the heading, row color schemes, scrolling width, direction and speed. Each **Testimonial** block defines one review.

![Featured Testimonials settings and storefront preview](/images/en/testimonial-featured.png)

## Add and configure the section

1. Go to **Shopify admin → Online Store → Themes → Customize**.
2. Open the template you want to edit and choose **Add section → Featured testimonial** in the page content area.
3. Set the section color scheme, heading and heading size.
4. Choose separate color schemes for the top and bottom card rows.
5. Expand the section and click **Add Testimonial**. Configure its image, rating, quote and author.
6. Add other reviews and drag blocks to change their order.
7. Set scrolling width, direction, speed and hover pause. Preview desktop and mobile, then click **Save**.

This section cannot be added to header, footer or custom overlay groups. Repeated cards at the edges support continuous scrolling; you do not need to duplicate reviews manually to extend the band.

## Color scheme

Choose the global scheme for the section. The screenshot selects the second scheme thumbnail in the first row for the overall heading and review area.

Click **Edit scheme** to change the scheme. Changes also affect other areas using it. Card colors are configured separately under Cards.

## Marquee

| Setting | Current screenshot value | Purpose |
| --- | --- | --- |
| **Marquee width** | **Full width** | Chooses page content width or full width for the scrolling area. |
| **Direction** | **Right to left** | Sets the scrolling direction. |
| **Speed** | **Normal** | Sets the movement speed. |
| **Pause on hover** | **Enabled** | Pauses scrolling when hovered on devices that support hover. |

### Width and direction

- **Page width** follows the page content width and is the package default.
- **Full width** uses the full width and is selected in the screenshot.
- **Right to left** moves content from right to left, matching the screenshot and default.
- **Left to right** moves content from left to right.

Marquee width controls the scrolling area, rather than individual card widths. With Full width selected, check how cards enter and leave the edges and join across scrolling cycles.

### Speed and pause

Speed offers **Slow, Normal and Fast**. The screenshot selects Normal, matching the default. For longer reviews, use a comfortable speed and enable hover pause to allow reading time.

Pause on hover is enabled in both the screenshot and package default. Touch devices do not support persistent hover, so check mobile readability separately. These controls set continuous scrolling behavior, rather than a timed interval for switching individual reviews.

## Testimonial blocks

Each **Testimonial** represents one review. Select an existing block in the left sidebar to edit it, or use **Add Testimonial** to create another.

| Setting | Current screenshot value | Purpose |
| --- | --- | --- |
| **Image** | No selected image thumbnail visible | Chooses the image for this review card. |
| **Show image** | **Enabled** | Controls whether the card includes an image area. |
| **Star rating** | `5` | Sets the card's star rating. |
| **Quote** | Example copy below | Adds the review text, with rich-text formatting. |
| **Author name** | `Alexandria Maria` | Sets the author attribution, with inline rich-text formatting. |

### Image and visibility

Use **Image → Select** to choose or upload an image, or explore free images. This image belongs to the individual Testimonial, rather than being a shared section hero image.

**Show image** is enabled in the screenshot, matching the default. When enabled, the card displays its image area. If no image is selected, the theme uses a decorative placeholder, such as the product line drawings in the preview. Disable Show image for a text-only review card.

### Rating, quote and author

**Star rating** ranges from **1–5 stars**, in steps of **1**. The screenshot uses `5`, matching the default. Set the value to match the actual review.

The screenshot's Quote reads:

> A calm, considered edit that makes everyday skincare feel easier to explore.

Quote supports rich-text paragraphs, bold, italic, links and lists. Keep copy concise, and check the visible area and reading experience for longer reviews.

The screenshot sets **Author name** to `Alexandria Maria`, displayed as the attribution on the card. The package default is `Customer name`. Check wrapping and card layout with longer names.

### Reorder and remove blocks

- Click **Add Testimonial** to add another review.
- Drag Testimonial blocks in the left sidebar to change the content order, then check the arrangement across both rows in the preview.
- **Remove block** at the bottom of the settings removes only the selected review.

## Custom CSS

**Custom CSS** is a section styling control provided by the theme editor. Use the existing color, width, speed and padding settings first. After adding local styles, check card layouts, mobile presentation and loop continuity.

## Save and check

- Confirm the heading reads Beyond clients. Trusted partners. at 2X large.
- Check text and rating contrast on the dark top-row and light bottom-row cards.
- Verify Full width scrolling moves right to left at Normal speed without noticeable jumps.
- Test hover pause on desktop and review readability on mobile.
- Check each block's image visibility, rating, quote and author.
- Review the `32 px` top and bottom padding alongside adjacent sections.
