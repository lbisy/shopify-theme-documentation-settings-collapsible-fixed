# Collection list

Collection list displays selected collections as cards, providing entry points to product categories or curated ranges. You can set separate desktop and mobile sizes for both the section heading and the card titles.

## Add and configure the section

1. Go to **Shopify admin → Online Store → Themes → Customize**.
2. Open the template you want to edit and choose **Add section → Collection list** in the page content area.
3. Set the color scheme, heading and heading alignment.
4. Click **Collections → Select** and choose up to **12 collections**.
5. Adjust the card titles, navigation arrows and padding. Preview desktop and mobile, then click **Save**.

This section cannot be added to header, footer or custom overlay groups.

## Color scheme

Choose the global color scheme used by the section. In the screenshot, the second scheme thumbnail has a blue selection border.

Click **Edit scheme** to change the selected scheme. Changes to a global scheme also affect other areas using it, so review those areas as well.

## Heading and collections

| Setting | Current screenshot value | Purpose |
| --- | --- | --- |
| **Heading** | `Shop by category` | Sets the section heading above the collection cards. |
| **Desktop heading size** | **Extra large** | Sets the section heading size on desktop. |
| **Mobile heading size** | **Extra large** | Sets the section heading size independently on mobile. |
| **Heading alignment** | **Center** | Aligns the section heading to the left or center. |
| **Collections** | Select button shown; selected collections are not visible | Chooses the collections to display, up to 12. |

Both heading size controls offer **Extra small, Small, Medium, Large, Extra large, 2X large, 3X large and 4X large**.

The screenshot shows **Extra large** for the mobile heading. The package declares **Medium** as its default. The table records the current screenshot configuration, not a change to the default.

Use the Collections picker to select collections; you do not need to add individual Collection blocks. Check that each card links to the intended collection page.

## Cards

| Setting | Current screenshot value | Purpose |
| --- | --- | --- |
| **Desktop card title size** | **Heading: Medium** | Sets the collection card title size and style on desktop. |
| **Mobile card title size** | **Text: Large** | Sets the collection card title size and style independently on mobile. |
| **Show navigation arrows** | **Enabled** | Controls whether navigation arrows are shown for the card list. |

**Desktop card title size** options:

- **Heading: Medium**
- **Heading: Small**
- **Text: Large**
- **Heading: Extra small**
- **Text: Default**

**Mobile card title size** options:

- **Text: Extra large**
- **Text: Large**
- **Text: Default**
- **Heading: Extra small**
- **Text: Small**

Card title sizes are independent of the section heading sizes. Check long collection names for wrapping on mobile. With navigation arrows enabled, also check that cards extending beyond the visible area are easy to browse.

## Padding

| Setting | Current screenshot value | Purpose |
| --- | --- | --- |
| **Padding top** | `32 px` | Adjusts the space above the section content. |
| **Padding bottom** | `32 px` | Adjusts the space below the section content. |

Use the sliders or numeric inputs to adjust either value from **0–100 px**, in **4 px** steps. Both screenshot values match the package defaults of `32 px`.

## Custom CSS and removing the section

The **Custom CSS** panel at the bottom of the screenshot is a section styling control provided by the theme editor. It is not an additional Collection list schema field. Expand it when you need local styling changes.

**Remove section** removes this section from the current template; it does not delete collections from Shopify admin. Before saving, check whether other pages also use the template.

## Save and check

- Confirm the heading text, alignment and color scheme.
- Select the intended collections and test each card link.
- Review section headings and card titles on desktop and mobile, especially long names.
- Check that navigation arrows appear and work as expected.
- Confirm that the `32 px` top and bottom padding works with adjacent sections.
