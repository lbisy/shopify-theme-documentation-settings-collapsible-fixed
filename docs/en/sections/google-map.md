# Google Map

The **Google map** section embeds an interactive Google Map in a page or template. Use it to show a store, showroom, pickup point, service area, or another customer-facing location.

![Google Map settings and storefront preview](/images/en/google-map.png)

## Add the section

1. In **Shopify Admin**, go to **Online Store → Themes**.
2. Find the theme you want to edit and click **Customize**.
3. Open the required page or template.
4. Click **Add section → Google map**.
5. Turn on **Show Google map**.
6. Paste the complete Google Maps `<iframe>` into **Map embed code**.
7. Adjust the map height and section spacing.
8. Check the map in the preview, then click **Save**.

The section does not search for an address or generate a map from plain text. It renders the embed code supplied in the settings.

## Show Google map

Use **Show Google map** to control whether the embedded map is displayed. The setting is enabled in the screenshot.

Turn the map off when preparing the section, temporarily hiding a location, or troubleshooting an embed. The code can remain saved while the map is hidden. Before publishing, confirm the hidden state does not leave unexpected empty space and that any privacy or consent integration handles the external map correctly.

## Get the Google Maps embed code

The simplest method is to copy the embed HTML generated by Google Maps:

1. Open Google Maps on a desktop browser.
2. Search for the exact business, address, or location.
3. Open **Share** and choose **Embed a map**.
4. Select an appropriate initial map view or size.
5. Click **Copy HTML**.
6. Paste the entire `<iframe>...</iframe>` code into **Map embed code**.

Do not paste the address by itself or use the regular share link from the **Send a link** tab. The field expects iframe HTML. After pasting, confirm the `src` points to a Google Maps embed URL and that the opening and closing iframe tags are complete.

## Map embed code

The screenshot contains an iframe with a Google Maps embed URL, full-width layout, no border, lazy loading, fullscreen permission, and a referrer policy. A typical structure looks like this:

```html
<iframe
  src="https://www.google.com/maps/embed?..."
  width="100%"
  height="450"
  style="border: 0"
  loading="lazy"
  allowfullscreen
  referrerpolicy="strict-origin-when-cross-origin"
  title="Map showing the store location">
</iframe>
```

This is a structural example only. Copy the real URL generated for the store location instead of using the abbreviated `...` value.

Recommended iframe attributes:

- **`src`**: the complete Google Maps embed URL for the intended location.
- **`width="100%"`**: allows the map to follow the responsive section width.
- **`style="border: 0"`**: removes the browser's default iframe border.
- **`loading="lazy"`**: delays loading until the map approaches the viewport.
- **`allowfullscreen`**: permits supported fullscreen map views.
- **`referrerpolicy`**: retain the value generated by Google; current API examples recommend `strict-origin-when-cross-origin`.
- **`title`**: provide an accessible description such as `Map showing the Shanghai store location`.

::: warning Paste trusted iframe code only
The field accepts markup. Paste code only from Google Maps or another source explicitly approved by the store owner. Do not add unknown scripts, event handlers, tracking code, customer data, passwords, unrestricted API keys, or unrelated HTML.
:::

## Map height

**Map height** controls the visible height of the embedded map in pixels. The screenshot uses `640 px`.

A taller map makes navigation and zoom controls easier to use but can dominate the page and add scrolling. A shorter map keeps the page compact but must leave enough room to interact with the map. Google Maps embeds should not be reduced below their supported minimum dimensions.

The iframe copied from Google can also contain a `height` attribute. The theme's **Map height** setting is intended to control the final section height; if the result does not match the selected value, check for conflicting inline iframe height, Custom CSS, or theme styles.

Review the final height on a typical desktop, tablet, and narrow mobile screen. A value that works on desktop might feel excessive on mobile.

## Padding

- **Padding top** controls the space above the map.
- **Padding bottom** controls the space below the map.

The screenshot uses `32 px` for both values. Equal values are a balanced starting point. Reduce them when the adjacent section already has generous spacing, or increase them when the map needs clearer separation from text, forms, or the footer.

## Custom CSS

Use **Custom CSS** only for small, section-scoped presentation changes that are not covered by Map height and padding. For example, it can adjust the outer container width, border radius, or overflow behavior.

CSS on the Shopify page cannot style roads, labels, markers, or controls inside the cross-origin Google iframe. Do not cover Google attribution, map controls, or keyboard focus. Recheck custom rules after theme updates.

## Location accuracy and customer guidance

Before publishing:

- Confirm that the pin identifies the intended entrance or pickup location, not only a city or district.
- Verify the business name, address, and route destination in Google Maps.
- Test **Directions** and other visible map controls.
- Place the written address, opening hours, phone number, and accessibility or parking instructions in a nearby text section; do not make the map the only source of essential location information.
- If the store has multiple locations, use clearly labeled maps or link to a dedicated locations page instead of presenting one map without context.

## Privacy, availability, and performance

Google Maps is third-party content and can make external requests or set cookies depending on the visitor's region and Google configuration. Confirm that the store's privacy notice and consent tool handle the embed as required for the markets being served.

The map can also be blocked by browser privacy tools, content-security policy, consent settings, or regional network restrictions. Keep the written address and a direct directions link available as a fallback. Lazy loading reduces initial page work, but the map still adds third-party resources when loaded.

## Before publishing

1. Confirm the iframe comes from the intended Google Maps location.
2. Verify the pin, business name, address, directions, and zoom level.
3. Check that the map fills the section width without horizontal scrolling.
4. Test the configured height and padding on desktop, tablet, and mobile.
5. Operate zoom, pan, directions, fullscreen, and keyboard focus where available.
6. Confirm the iframe has a useful accessible title and that essential location details also exist as text.
7. Test with the store's cookie consent and content-security settings.
8. Check the fallback experience when Google Maps is blocked or unavailable.
9. Verify that Custom CSS does not hide attribution or controls.
10. Save the theme and test the published or preview storefront outside the theme editor.

For embed details, see Google's [Maps embedding documentation](https://developers.google.com/maps/documentation/embed/embedding-map).
