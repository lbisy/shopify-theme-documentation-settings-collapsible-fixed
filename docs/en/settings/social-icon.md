# Social icon

Use **Social icon** settings to add links to your store's social profiles. When a supported theme area displays social links, each completed field produces the corresponding platform icon.

## Open the Social icon settings

1. In Shopify admin, go to **Online Store > Themes**.
2. Find the theme you want to edit and click **Customize**.
3. Open **Theme settings > Social icon**.

![Social icon settings and storefront preview](/images/en/settings/social-icon.png)

Only keep links for profiles that belong to the store or brand. Leave unused platform fields blank so their icons are not displayed.

## Enter valid profile links

Paste the full public profile or channel URL into each field:

- Begin the address with `https://`.
- Use the profile URL, not only a username, handle, or numeric placeholder.
- Open the URL in a browser before saving and confirm it reaches the intended public profile.
- Remove tracking parameters or temporary login links.
- Check capitalization and the exact account handle.

For example, replace `1`, `2`, and `3` with addresses such as `https://www.facebook.com/yourbrand`, `https://www.instagram.com/yourbrand`, and `https://www.youtube.com/@yourbrand`.

## Placement and appearance

Social icons appear only in theme sections that support them, such as a header, footer, or social-media block. If a valid link is saved but no icon appears, confirm that the relevant section has social icons enabled and that the platform is supported there.

Icon size, color, spacing, and hover or focus appearance can depend on the section and active color scheme. Review every location where social links appear on desktop and mobile.

## Accessibility and maintenance

Test the icons using both a pointer and keyboard. Each icon should have a visible focus indicator and an accessible name that identifies its platform. Confirm that opening an external profile does not make it difficult to return to the store.

Social account names and URLs can change. Review the links periodically and whenever a profile is renamed, migrated, or discontinued.

## Recommended workflow

1. Remove placeholder values and links for unused platforms.
2. Paste each complete `https://` profile URL.
3. Open every URL and verify the destination.
4. Save the theme settings.
5. Check each supported header, footer, or social section.
6. Test desktop, mobile, keyboard focus, and link behavior.

## Save and test

Click **Save**, then confirm:

- Every completed field displays the correct platform icon.
- Each icon opens the intended public brand profile.
- Blank platforms do not appear.
- No field contains a username-only or placeholder value.
- Icons remain visible and correctly spaced in every color scheme.
- Keyboard focus is clear and the links are accessible on mobile.
